Se valida y guarda el código completo. Se activa y evalúa en cada ciclo si coincide con un motor revisado; los programas distintos se guardan, pero no se ejecutan automáticamente.
Importante: las fórmulas simples usan un subconjunto seguro de Python. Los programas completos se guardan. Cada programa compatible con un motor revisado se puede activar y evaluar en cada ciclo; el código Python arbitrario no se ejecuta automáticamente. Ninguna estrategia envía órdenes reales. Para las fórmulas simples: asignaciones, if/else, comparaciones, AND/OR/NOT y abs/min/max/round. Ejemplo: entry = price > 5 and rvol >= 2 y después entry and change_pct > 1. Variables disponibles: price, bid, ask, change_pct, gap_pct, volume, rvol, premarket_change_pct, float_shares, ema20, macd, macd_signal, bollinger_upper y bollinger_lower. Cada variable necesita datos reales; las variables sin datos bloquean la evaluación y nunca se inventan. Sin almacenamiento compartido, las estrategias se guardan solo en este navegador. Conectado, se guardan en PostgreSQL. No envían órdenes; Tradeboot permanece en modo de solo lectura.
